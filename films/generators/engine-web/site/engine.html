How it works

One sheet, one station, one clock

The sheet

Each station starts as six lines: a title, a claim, a fact, a line for Natori, a line for Rogue, and a check that prints where the source and the record disagree. The words are checked before a single frame is made.

The clock

Every station runs fifteen seconds. The year rolls in by 1.9, Natori speaks from 2.4, the quick fact rises in the gap, Rogue answers, and the check lands before the station hands on.

The mirror

Station k mirrors station 13 − k, each shot plays forward and then back, and the last station returns to the first frame. The film reads the same returning: 19138 · 83191.

The render

The same code that plays here renders the finished 1080p films frame by frame, so what you scrub on this page is exactly what ends up in the film.
