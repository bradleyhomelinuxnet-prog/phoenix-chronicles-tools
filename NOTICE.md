# Notice

## Third-party material

The reverse-engineering documents under docs/ are analytical/critical work
describing the behaviour of the closed-source Ophis v9 Windows application.
They quote small excerpts of that application's source code with file:line
citations, as necessary to explain the engine's operation. Neither this
repository nor its authors distribute the Ophis binary or its source code;
if you want to run Ophis itself, obtain it from its author.
